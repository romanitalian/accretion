# Accretion

Космическая головоломка для iPhone и iPad. Ты — звезда. Касайся, чтобы выбрасывать массу и лететь. Поглощай звёзды меньше себя. Крупные звёзды, чёрные дыры и другие объекты высасывают твою массу. Цель каждого уровня — вырасти, выжить или выполнить особое условие.

Вдохновлено Osmos. Своё название, графика, звук и механики.

## Возможности

- **Играть сразу.** Запуск открывает уровень. Регистрации, меню и реклама не нужны. Работает офлайн.
- **Управление одним пальцем.** Касание — выброс массы в сторону касания. Удержание — непрерывная тяга. Двумя пальцами — масштаб.
- **Кампания.** 30+ уровней. Каждые несколько уровней добавляется новый объект, при первой встрече коротко объясняется.
- **Ежедневный уровень.** Один и тот же для всех в данный день, без сети.
- **Песочница.** Включай любые объекты и задавай сложность.
- **Звёзды за уровень.** 1–3 звезды за экономию массы. Лучшие результаты сохраняются.
- **Повторы.** Лучшее прохождение каждого уровня можно посмотреть из меню. Хранятся только касания, файлы маленькие.
- **Достижения.** 14 штук, например «Дзен», «Бильярд», «Космонавт на борту».
- **Облики звезды.** Шесть цветов, открываются звёздами кампании.
- **Звук.** Фоновая музыка генерируется на лету, у каждого мира своя гармония. Громкость музыки и звуков регулируется отдельно.
- **Доступность.** Контрастные цвета для дальтоников. Уменьшение движения (Reduce Motion) отключает тряску, вспышки и пульсации.

## Объекты

| Объект | С какого уровня | Что делает |
|---|---|---|
| Охотник | 2 | Гонится за звёздами меньше себя, бежит от крупных |
| Беглец | 3 | Удирает от крупных звёзд, лёгкая добыча |
| Чёрная дыра | 4 | Гравитация, орбиты, всё упавшее исчезает |
| Сверхновая | 6 | Взрывается через 18–32 с, разлетаясь осколками |
| Делящаяся звезда | 9 | Раскалывается на две половинки, когда ей угрожают |
| Пульсар | 8 | Каждые 4 с отталкивает всё вокруг |
| Комета | 9 | Отскакивает без потерь, оставляет хвост из еды |
| Туманность | 11 | Замедляет движение, полна пыли |
| Антиматерия | 12 | Уничтожает массу обеих сторон |
| Червоточина | 13 | Пролезают только звёзды меньше входа |
| Двойная звезда | 14 | Две большие звезды кружат друг вокруг друга |
| Космонавт | 2 | Маленький дрейфующий, съедобный |
| Планета | 7 | Твёрдая: от неё отскакиваешь, съесть нельзя |

Точные уровни задаются в `Accretion/Progress/Progress.swift`.

## Требования

- macOS с Xcode 27 (или версия с поддержкой iOS 17+)
- [XcodeGen](https://github.com/yonaskolb/XcodeGen): `brew install xcodegen`
- Для установки на устройство: подключённый iPhone или iPad (кабелем или по Wi‑Fi) и Apple Developer team в `project.yml`

## Сборка и запуск

Все команды собраны в `Makefile`. Список: `make help`.

```bash
make gen          # VERSION.md → project.yml и перегенерировать Xcode-проект
make version      # текущая версия и билд
make bump         # билд +1 (перед каждой загрузкой)
make build        # сборка для симулятора
make sim          # собрать и запустить в симуляторе iPhone (make sim-ipad — iPad)
make test         # юнит-тесты движка
make install      # собрать Release и поставить на iPhone (install-ipad, install-all)
make devices      # список подключённых устройств
make icon         # перерисовать иконку приложения
make archive      # подписанный архив (локально, ничего не загружает)
make testflight   # архив + загрузка в App Store Connect / TestFlight
make release      # bump + test + testflight
make screenshots  # скриншоты для App Store (iPhone 6.9" + iPad 13") через UI-тесты
make screenshots-framed  # + рамки устройств (fastlane frameit)
make screenshots-text    # + подписи из screenshots/text-overlays.json
make clean        # удалить сборку
```

Устройство по умолчанию задано в `Makefile` переменной `DEVICE`. Чтобы поставить на другое:

```bash
make install DEVICE=<UDID из make devices>
```

Симулятор выбирается автоматически (первый доступный iPhone 17 Pro) или переменной `SIM`.

> Если установка прошла, но приложение не открылось, разблокируй устройство и открой Accretion вручную.

## Отладочные запуски

Только для Debug-сборки (`make sim`). Передаются как аргументы запуска через `xcrun simctl launch`:

| Аргумент | Что показывает |
|---|---|
| `-AccretionQuickWin YES` | Уровень, который выигрывается за секунду: экран итога |
| `-AccretionSupernovaDemo YES` | Сверхновая рядом с игроком |
| `-AccretionAstronautDemo YES` | Космонавт среди звёзд всех размеров |
| `-AccretionBlackHoleDemo YES` | Чёрная дыра с планетами |
| `-AccretionShowcase YES` | Все объекты в одном уровне |

## Структура проекта

```
Accretion/
  App/          точка входа, SwiftUI-оболочка, кнопки, шаринг
  Engine/       физика и правила: тела, мир, генератор уровней (чистый Swift, без UIKit)
  Render/       SpriteKit-сцена: отрисовка, камера, эффекты, поверхность звёзд, шейдер
  Audio/        генеративная музыка и звуковые эффекты (AVAudioEngine)
  Progress/     прогресс, настройки, повторы, достижения, облики
  UI/           меню, песочница, секции облика и достижений
  Assets.xcassets/  иконка приложения
AccretionTests/     юнит-тесты движка
scripts/            генерация иконки
project.yml         описание проекта для XcodeGen
ExportOptions.plist для выгрузки архива в TestFlight
IDEAS.md            журнал идей и сделанного
PLAN.md             исходный план игры
```

Движок не знает о рендере: `World.step(dt)` меняет состояние, сцена его только показывает. Поэтому правила проверяются тестами без симулятора.

### Детерминизм

Физика идёт фиксированным шагом 1/120 с, генератор уровней — от числа-сида. Одинаковый сид и одинаковые касания дают одинаковый результат. На этом держатся повторы и ежедневный уровень.

## TestFlight

Версия и номер билда задаются в `VERSION.md`. Сборка для TestFlight собирается командой `make archive` (локально, без отправки). Загрузка — `make testflight`. Перед первой загрузкой нужна запись приложения в App Store Connect с bundle id `com.romanitalian.accretion`.

В `project.yml` уже указано, что шифрование не используется, и есть манифест приватности (`Accretion/PrivacyInfo.xcprivacy`): данные не собираются, трекинга нет, в UserDefaults хранятся только прогресс и настройки.

## Лицензия

Личный проект, все права на код и графику у автора.

## Публикация в App Store (fastlane)

Карточка приложения хранится в проекте: тексты в `fastlane/metadata/<язык>/`, категория и контакты для ревью там же, возрастной рейтинг в `fastlane/rating.json`, ответы App Privacy в `fastlane/app_privacy_details.json`. Политика конфиденциальности — [PRIVACY.md](PRIVACY.md).

Один раз:
1. `make store-setup` — поставить fastlane и создать `fastlane/.env`.
2. В App Store Connect → Users and Access → Integrations создать API-ключ (роль App Manager), вписать его в `fastlane/.env`.
3. `make store-create-app` — создать запись приложения (вход по Apple ID: API этого не умеет).
4. `make store-privacy` — App Privacy: «данные не собираются» (тоже через Apple ID).
5. Цена (бесплатно) и страны — один раз на сайте App Store Connect.

Каждый релиз:
```bash
make screenshots-text   # новые скриншоты (если менялся вид)
make store-screenshots  # положить их в fastlane/screenshots/
make ship               # билд +1, тесты, TestFlight, карточка, отправка на ревью (спросит)
```
`make store-check` проверяет карточку до загрузки: лимиты Apple, незаполненные TODO, размеры скриншотов, открываются ли ссылки.
